2. Device Permissions & Purpose of Use

Status Bar Notifications POST_NOTIFICATIONS
Displays real-time download and upload speed meter in the notification shade and sends instant alerts when battery is full or low.
Display Over Other Apps SYSTEM_ALERT_WINDOW
Renders draggable floating speed bubble and high-fidelity charging animations when the device is plugged in.
App Data Usage Access PACKAGE_USAGE_STATS
Calculates local cellular and Wi-Fi data consumption per installed app using native Android NetworkStatsManager.
Wi-Fi Network Information ACCESS_FINE_LOCATION
Required by Android OS security policy to read connected Wi-Fi router SSID name and channel frequency. No GPS location tracking is conducted.
Auto-Start on Reboot RECEIVE_BOOT_COMPLETED
Automatically resumes background network speed monitoring and battery alerts whenever your device restarts.
